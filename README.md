## How to assemble

 The snail body itself is divided into two bodies so follow these steps:
 
1) Take the PCB and place it on the back side of the hole on the right side of the body and screw the screw from inside out in such a way that the PCB is mounted and hold using screw head use the smaller nail set for this.
2) Solder the 7 pin connector and stuff to the PCB
3) Place the esp 32 at bottom and connect the esp32 pins to the 7 pin connector of the PCB using wires or jumper cables.
4) now place the screen from inside out and connect it to the esp 32
5) same for speaker , amplifier, mic.
6) now from the back hole slide the USB-C cable and connect the ESP-32
7) Now using the longer screw set and screw the two bodies together

**pro tip:** while screwing the screws in use the brass-heat set insert which can be pushed inside the screw holes by placing it on top and using the solder heat and push the insert in the hole so it is easier to hold them.
